# ✨ Features

## 1. 📊 Dynamic Data Display

The application loads data from a JSON file and dynamically displays it in the UI.

## 2. 🧩 Reusable Components

The UI is divided into smaller React components, making the code easier to understand, maintain, and reuse.

## 3. 🔄 Interactive State Management

The project uses React state to manage changing data and update the interface automatically when the state changes.

# ⚛️ React Questions & Answers

## 1. What is JSX, and why is it used in React?

JSX is a way to write html inside javaScript and typescript

---

## 2. What is the difference between props and state?

Props are usuing data from parents component to a child components.

State is data that a component manages and can change over time.

```text
Props : passed into a component
State : managed inside a component
```

---

## 3. What does the useState hook do, and where did you use it in this project?

useState lets a component store and update data.

I used it to store the data that is displayed and manage changes to that data.

---

## 4. What does the useEffect hook do, and why did you need it to load the JSON data?

useEffect is used for side effects such as loading data.

I used it to load the JSON data when the component first appeared.

---

## 5. Why does every item in a .map() list need a unique key prop?

React needs a unique key to identify each item in a list.

---

## 6. What is conditional rendering?

Conditional rendering means showing different UI depending on a condition.

---

## 7. How do you pass data from a parent component to a child component, and how does a child send something back to the parent?

A parent sends data to a child using props.

The child can communicate back to the parent by receiving a callback function as a props
